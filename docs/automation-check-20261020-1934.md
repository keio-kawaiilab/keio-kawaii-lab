# 2026-10-20 CUTIE STREET受付種別の訂正

## 確認した根拠

- https://cutiestreet.asobisystem.com/news/detail/92733
  - 10月15日告知の件名は広島・愛知公演の「アップグレード抽選受付」。
  - 受付は2026-10-15 12:00〜10-20 23:59（日本時間）。11月14・15・28・29日の4公演が対象。
  - 本文の「年会費コース会員先行」は、指定席チケットを既に購入した申込対象者の条件であり、新しい年会費会員先行受付ではない。
  - 本文からリンクする正規受付 https://cutiestreet.asobisystem.com/feature/4c423486cd702a636c35ded5a973d8e4?_normalbrowse_=1 はログイン画面。公開本文の確認に留め、ログイン・申込は行っていない。

## 原因と修正

recent-official-body の汎用本文パーサーが資格条件を別受付と誤認し、各公演にアップグレードと年会費会員先行の両方を表示していた。出典記事・グループ・開催日・受付期間・誤った種別の全条件が一致する行だけを訂正する。新規取得時にも同じ補正を適用し、次回の再発を防ぐ。ID、日時、申込期間、出典を変更せず、別公演や別受付には適用しない。公開データは既存の監査・生成・Pages経路で更新する。

### 公開後の追加検証

東京2公演の追加受付は公開カレンダーへ反映された。公演詳細では `ticket-resale-ui.js` の部分一致が「プリセール」内の「リセール」を誤検出し、受付種別・ボタンをリセール表示へ変更していた。プリセール/presaleを除外してからリセールを判定するよう変更し、日本語/英語の先着先行が変装されず、真のリセールは認識される回帰テストを追加した。

修正版のPages配信成功後も旧URL版のスクリプトがキャッシュされていたため、既存のローダー・HTML生成・リセール更新ジョブのキャッシュ版番号を202610201950へ揃えた。train-status.jsはローダー参照URLだけの変更で、交通機能の挙動は変更していない。定期ジョブが古い番号へ戻さないこともNode回帰テストで検証する。

19:37:36更新版で、カレンダーの誤った年会費先行帯は消えていた。一方、公演詳細の「チケット販売の流れ」は恒久履歴を別途読むため、過去に保存された誤分類が12行残っていた。`archive_ticket_history.py`にも同じ出典・日付・期間・ツアーに限定した訂正を追加。誤観測そのもの、ID、観測日時、申込期間、各公演は削除せず保存し、公式92733を根拠にその誤分類だけを公開不適格として記録する。正しいアップグレード履歴、別期間の年会費会員先行は引き続き保持・公開する。
