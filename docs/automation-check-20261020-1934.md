# 2026-10-20 CUTIE STREET受付種別の訂正

## 確認した根拠

- https://cutiestreet.asobisystem.com/news/detail/92733
  - 10月15日告知の件名は広島・愛知公演の「アップグレード抽選受付」。
  - 受付は2026-10-15 12:00〜10-20 23:59（日本時間）。11月14・15・28・29日の4公演が対象。
  - 本文の「年会費コース会員先行」は、指定席チケットを既に購入した申込対象者の条件であり、新しい年会費会員先行受付ではない。
  - 本文からリンクする正規受付 https://cutiestreet.asobisystem.com/feature/4c423486cd702a636c35ded5a973d8e4?_normalbrowse_=1 はログイン画面。公開本文の確認に留め、ログイン・申込は行っていない。

## 原因と修正

recent-official-body の汎用本文パーサーが資格条件を別受付と誤認し、各公演にアップグレードと年会費会員先行の両方を表示していた。出典記事・グループ・開催日・受付期間・誤った種別の全条件が一致する行だけを訂正する。新規取得時にも同じ補正を適用し、次回の再発を防ぐ。ID、日時、申込期間、出典を変更せず、別公演や別受付には適用しない。公開データは既存の監査・生成・Pages経路で更新する。
